**Classify**

**A live semantic index of the open web.**

Classify builds ContentGraph, a URL-level index that describes pages by what they are about. It gives developers and agents page-level context for their applications.

## Page understanding, through an API

An application can classify pages as it encounters them, or look up classifications in an existing index. ContentGraph provides the indexed route.

A lookup depends on coverage. A URL without a matching record returns an unknown result. Treat that as missing information, not a judgment about the page.

## Get access

[Request access through Classify](https://classify.ai). Requests are reviewed manually. API use requires approval and an API key; submitting a request does not grant immediate access.
